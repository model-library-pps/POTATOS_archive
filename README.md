**Name**\
POTATOS

**Program type**\
Crop growth simulation model

**Available since**\
Fri, 12/31/1999 - 12:00

**Description**\
POTATOS is a simple crop growth model of the LINTUL-type. POTATOS has been used for calculating the impacts of climatic change on potato production over Europe. The main simulated processes are: photosynthesis, phenological development, assimilate allocation to crop organs, soil evaporation, crop transpiration, soil water balance.
